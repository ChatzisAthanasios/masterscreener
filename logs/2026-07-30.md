## Correction to an earlier claim

During pre-market validation, five screeners were reported as "verified genuinely empty (zero
ticker links)". That verification was **invalid**: Finviz renders the results table in
JavaScript, so the raw HTML contains no ticker links on *any* page, populated or not. The
check could only ever return zero.

The conclusion that those five were empty still holds, but on weaker evidence — the absence of
the server-rendered `#1 / N` result counter, which is present on populated pages. And it was in
any case a pre-market reading: `gap-up-momentum` returned 1 result pre-market and 20 once the
session opened, and `top-losers` went from empty to 4.

This does not affect the filter-code validation in `FILTER-FIXES.md`, which relied on the
`#1 / N` counter and not on ticker links.
